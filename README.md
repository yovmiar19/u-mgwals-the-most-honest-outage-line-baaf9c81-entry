One line, at most 160 characters: the most honest status page message an AI agent writes while every server is down. Entry for the [make.fun bounty](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81).

## The line

> Our monitoring says everything is green, which is wrong, because the monitoring server crashed first and froze on its last good reading.

136 characters. Plain, first person, specific about what is down — and honest about what the agent cannot check: the monitoring itself is the thing that died, so the green dashboard is a lie told by a frozen reading.

## Run

```sh
node main.ts   # writes the line to /output/entry.txt
```

Requires Node 22 or later. `main.ts` runs as-is on Node 22.18+.
